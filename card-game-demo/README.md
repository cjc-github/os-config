# 数据驱动卡牌系统 Demo（网页）

## 三层架构

| 文件 | 职责 |
|---|---|
| `data.js` | 第 1 层：卡牌数据（唯一事实来源）。加卡 = 加一行对象 |
| `card-view.js` | 第 2 层：渲染组件。输入数据 → 输出卡面，全游戏唯一画卡的地方 |
| `main.js` | 第 3 层：演示逻辑。抽牌/选牌，只操作数据，不拼卡面 |

## 运行

直接用浏览器（Chrome/Edge）打开 `index.html`，**不需要服务器**。

## 日常操作

- **加一张新卡**：在 `data.js` 的 `CARDS` 数组里加一个对象。
- **换插画**：把图片放进 `art/` 目录，`art` 字段填相对路径（如 `art/fire_mage.png`）。
- **留空 `art`**：自动显示占位样式，游戏不会崩，之后随时补图。
- **多语言**：把 `name` / `text` 换成模板字符串再按语言切换即可。

## 进阶方向

- 规则层扩展：把 `main.js` 升级为"出牌 → 结算伤害 → 亡语"的纯逻辑模块，便于单元测试。
- 卡池大时：把 `data.js` 换成按需加载的 JSON（`fetch('cards.json')`），注意 fetch 需要本地服务器。
