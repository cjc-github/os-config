# 水浒叶子 · 简化对战（网页版）

## 运行

用浏览器直接打开 `index.html`，无需服务器、无需安装。

## 三层架构

| 文件 | 职责 |
|---|---|
| `data.js` | 第 1 层：40 张叶子牌数据（唯一事实来源） |
| `card-view.js` | 第 2 层：叶子卡渲染组件（竖长卡面，数据→卡面） |
| `game.js` | 第 3 层：对战规则（比牌、计分、AI），只操作数据 |

## 玩法规则（简化版）

1. 40 张牌洗匀，双方各 20 张。
2. 每回合你先出一张，AI 出它手里最强的一张。
3. 比点数；点数相同比门：**万贯 4 > 索子 3 > 文钱 2 > 十字 1**。
4. 胜者赢得桌上两张牌；平局各得一张。
5. 20 回合后比赢牌数，多者获胜。

## 卡组说明（重要）

- 40 张 = **天罡 36 星 + 4 位知名地煞**（朱武、黄信、孙立、宣赞），只是"水浒好汉"题材的示例选角。
- **花色/点数分配是循环生成的示例**（第 i 张 → 门[i%4]，点数 i//4+1），保证四门各 1-10 点各一张。历史《水浒叶子》的好汉与点数真实对应关系版本不一，可整组替换 `data.js`，只需保持字段结构。
- 每张牌的数据字段：`id / 门 / 门值 / 点数 / 名号 / 绰号 / 称谓 / art`。

## 美术升级路径

叶子戏最大的卖点是**绣像**。现在没有插画时，卡面显示"名号首字"印章（四门配色），完全够用。

- 陈洪绶《水浒叶子》为 17 世纪版画，**已进入公有领域**，Wikimedia Commons 有高清扫描图，可免费商用。
- 把图放进 `art/` 目录，把对应卡的 `art` 字段填成相对路径即可（如 `art/song_jiang.png`）。
- 也可以在 Settings → Plugins → Image generation 配置图片生成插件后，用 `image_generate` 生成重绘版本。

## 缩放适配（重要）

卡面尺寸由 CSS 变量 `--leaf-w`（默认 108px）一个变量驱动，卡内所有字号/内边距均用 `em`，
所以**改一个变量，整张牌等比缩放，文字依然清晰**（文字是矢量的，不会糊）。

- 页面右上角"卡牌大小"滑块（70%–140%）即是演示。
- 想接入响应式：在媒体查询里改 `--leaf-w` 即可，例如手机端设为 `86px`。
- 若用 `transform: scale()` 缩放：视觉同样不受影响，但布局占位盒不变，需自行处理容器尺寸。
- **可读性下限**：基准字号是卡宽的 11.1%，卡宽低于约 90px 时效果文字会偏小，建议小屏改为「手牌横向滚动 + 保持卡牌尺寸」，而不是无限缩小。
- 位图插画缩小没问题（浏览器平滑下采样），但建议按实际显示尺寸出图以省内存。
